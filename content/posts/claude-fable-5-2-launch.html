On November 9, 2026, Anthropic released Claude Fable 5.2 and lowered the price of its top generally available model by a fifth. For anyone running coding agents or long automated jobs, the price is the news: the same kind of work now costs 20 percent less. This explainer covers what was announced, what it costs in practice, who can use it, and how to switch.

1. What was announced

  • A new version. Claude Fable 5.2 replaces Fable 5.1 as Anthropic's most capable generally available model.
  • A price cut. Input falls from $10 to $8 per million tokens, and output from $50 to $40.
  • A sibling with limited access. Claude Mythos 5.2 is listed at the same prices, with limited availability.
  • A faster option. A fast mode offers up to 2.5 times the output speed at twice the price.

Two modifiers from the pricing documentation are worth knowing:

  • Fast mode: $16 input and $80 output per million tokens, for up to 2.5 times the output speed.
  • US-only inference: 1.1 times the standard price on every token category.

For scale, the same table lists Claude Opus 5.5 at $4 input and $20 output. Fable 5.2 costs exactly twice as much, so it is the model for the hardest work, not for everything.

3. What that means for a real task

Agents reread their context on every step, so most of their input is served from the cache. Take a long coding task that uses 2 million input tokens, 1.5 million of them from the cache, and writes 100,000 tokens:

TokensAt 5.1 pricesAt 5.2 prices
Fresh input500,000$5.00$4.00
Cached input1,500,000$0.38$0.30
Output100,000$5.00$4.00
Total$10.38$8.30

The token counts are an invented example; the arithmetic is exact. Notice where the money goes: 100,000 output tokens cost as much as 500,000 fresh input tokens, and 1.5 million cached tokens cost thirty cents. Keeping the start of your prompts stable, so the cache can be used, saves more than any model switch.

5. How to switch in Claude Code

Fable is not the default model on any plan. You select it yourself:

/model fable

That is typed inside a session. To start a session on it from your shell:

claude --model fable

6. What to know before relying on it

  • Some requests are rerouted. Anthropic says requests flagged by its safety classifiers, most often in cybersecurity and biology, fall back to another model automatically. The product page names Opus 4.8 for cybersecurity and Opus 5 for biology. If you do security work, expect this, and look at the verification program the page describes.
  • Data is retained for safety monitoring. The product page states a 30-day retention by default, and describes an enterprise option compatible with zero retention.
  • Mythos is a separate track. It shares the price list but has limited availability.
  • Cheaper is not the same as cheap. At twice the price of Opus 5.5, routine edits and questions are better sent to a smaller model.
