How the page stays current

Nothing about the version or model is typed by hand. Claude Code reports it, and a small script publishes it.

  1. Claude Code Sends the current model and version to the status line command after each message.
  2. sync-status.sh Prints the status line and checks whether the model or version changed since the last publish.
  3. GitHub On a change, commits only status.json to main in the background.
  4. This page GitHub Pages redeploys, and the page reads the new status.json on load.

One-time setup on a new machine

  1. Clone this site with push access, for example to ~/swchoi1994.github.io.
  2. Make the script executable with chmod +x.
  3. Point the status line at it in ~/.claude/settings.json.
  4. Start Claude Code and send a message. The status line shows the model and version, and this page updates a minute or two later.
The script never touches your working tree. It builds the commit with git plumbing, so uncommitted work in the clone stays exactly as it was.
Terminal 
git clone https://github.com/swchoi1994/swchoi1994.github.io.git ~/swchoi1994.github.io
chmod +x ~/swchoi1994.github.io/claude-code-setup/sync-status.sh
~/.claude/settings.json 
{
  "statusLine": {
    "type": "command",
    "command": "~/swchoi1994.github.io/claude-code-setup/sync-status.sh"
  }
}

Troubleshooting

The shortest useful check for each symptom.

Old model shown Check the last synced time first. The status line only runs in interactive sessions, after a message. Send one message after /model, then allow a minute or two for GitHub Pages to redeploy.
Sync failing Read the sync log. Every publish is logged to .git/claude-status/sync.log in the clone. Most failures are push credentials: confirm with git -C ~/swchoi1994.github.io push --dry-run. Failed publishes retry after 10 minutes.
Update available Run claude update, then start a new session. The new version is published with the next status line refresh, and the badge turns green.
Custom status line Keep your own status line and pipe the same JSON through. In your existing script, after input=$(cat), add printf '%s' "$input" | ~/swchoi1994.github.io/claude-code-setup/sync-status.sh >/dev/null.
No status line Confirm the path and permissions. The command in statusLine must point to the script and the script must be executable. The script needs jq, node, or python3 to read the JSON from Claude Code.
