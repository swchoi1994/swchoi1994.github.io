Four steps to fix a Windows print queue that is stuck

Seongwoo Choi · 2026.10.29 · 2 min read

If a document is stuck in the print queue and later documents do not print, Microsoft recommends four steps: cancel the jobs, restart Print Spooler, clear the spool folder, and restart the printer and PC.

In this article

  • 1. Cancel the jobs in the queue first
  • 2. Restart the Print Spooler service
  • 3. Clear the spool folder only when cancellation fails
  • 4. Restart the printer and PC
  • Verification checklist

If you clicked the print command but the document is stuck in the queue and the next document does not print either, one job remaining in the queue is likely blocking the jobs behind it. Microsoft Support divides this situation into four steps: canceling the jobs, restarting the spooler, clearing the spool folder, and restarting the devices. This article organizes those steps. It is based on the official documentation, not on testing with an actual printer.

1. Cancel the jobs in the queue first

Go to Start > Settings > Bluetooth & devices > Printers & scanners, select the printer, and click Open print queue. Right-click a job in the list and select Cancel. If there are multiple jobs, cancel them all. If the issue is resolved here, the next steps are unnecessary.

2. Restart the Print Spooler service

Print Spooler is a Windows service that manages print jobs. Press Windows key + R, enter services.msc, and open the list of services. Find Print Spooler, right-click it, and select Restart. Jobs that were not removed in step 1 may also be cleared during this process.

3. Clear the spool folder only when cancellation fails

Use this method only when cancellation in step 1 does not work. First, stop Print Spooler by selecting Stop. In File Explorer, open C:\Windows\System32\spool\PRINTERS and delete all the files inside. Then, in the Services window, start Print Spooler again by selecting Start. The files in this folder are pending print jobs, so deleting them cancels those jobs. If an important document was waiting, first check that a separate copy of the original file remains. Deleting files in the folder may require administrator privileges.

4. Restart the printer and PC

Turn off the printer, wait at least 60 seconds, and turn it on again. On the PC, select Start > Power > Restart. After rebooting, try printing again with one short document. If you send a long document first, it is difficult to determine whether the cause is the same job.

Verification checklist

① Are there 0 jobs remaining in the queue? ② Is Print Spooler running after cancellation? ③ Does one short document print? ④ If the same document piles up again, are you checking Microsoft's document on troubleshooting printer connection and printing problems separately, since it may be a printer connection or driver issue? If even one of the four answers is no, moving to the next step is the way to save time.
