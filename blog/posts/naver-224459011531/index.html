How to check allowed settings when an app is blocked by Windows Firewall

Seongwoo Choi · 2026.10.30 · 3 min read

When an app cannot connect to the internet or be accessed from another device, Windows Firewall may be the cause. This article explains how to identify firewall issues and allow only the affected app.

When an app cannot connect to the internet or be accessed from another device, Windows Firewall (Microsoft Defender Firewall) may be the cause. The firewall allows or blocks connections based on criteria such as the app path, port, and network type. This article explains how to first determine whether the firewall is the problem and then allow a specific app. This is a troubleshooting sequence based on Microsoft support documentation, not the results of testing on an actual PC.

1. Check whether the firewall is the problem first

Not every connection problem is caused by the firewall. First, check whether Wi-Fi is connected and whether other websites or devices work. If the internet itself is not working, start by separating the connection issue according to the steps in the Wi-Fi troubleshooting article ↗. If only a specific app is blocked while other programs work normally, it is time to check the firewall's allowed settings.

2. Check the network type in Windows Security

Open the Windows Security app and select Firewall & network protection. Check whether the currently connected network is a domain, private, or public network. Microsoft explains that stricter security controls apply to public networks. Since the same app may work at home but be blocked on a public network such as one at a café, record the name of the network where the problem occurred.

3. Add the app to the allowed list

On the Firewall & network protection screen, select Allow an app through firewall. Selecting Change settings may prompt you for an administrator password or confirmation. If the app is listed, check its checkboxes. If it is not listed, select its file path under Allow another app. After changing the permission, close and reopen the app to check the connection.

4. Check two things if it is still blocked

First, check whether the Blocks all incoming connections option is enabled. When this option is enabled, it blocks all incoming connections and ignores the allowed list. Second, if the PC is managed by a company or school, you may be unable to change the firewall settings because of its policies, so check with the administrator.

5. Treat opening a port as a last resort

You can also open a specific port under Inbound Rules in Advanced settings. Microsoft explains that adding an app to the allowed list is less risky than opening a port. A port remains open until you close it manually, while an allowed app opens ports only when necessary. Create a port rule only when allowing the app does not solve the problem, and disable the rule when you no longer use it.

6. Troubleshooting checklist

① Check the internet and connections to other devices. ② Check the current network type in Windows Security. ③ Add the app to the allowed list and run it again. ④ Check the Blocks all incoming connections option and administrator policies. ⑤ If it still does not work, create only the necessary port rules with the minimum scope. Do not allow unfamiliar apps. Microsoft also recommends not allowing apps you do not recognize through the firewall.

The official sources referenced are Microsoft Support: Firewall and network protection in the Windows Security app ↗ and Microsoft Support: Risks of allowing apps through Windows Firewall ↗. Menu names may differ on the screen depending on the Windows version and language settings, so check them using the English names as well.
