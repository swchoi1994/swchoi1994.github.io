OpenAI 구형 모델 API 10월 23일 종료, 호출 중인 모델 ID부터 확인할 것

Seongwoo Choi · 2026.10.19 · 2분 읽기

OpenAI가 공식 Deprecations 문서에서 구형 모델 여러 개의 API 종료일을 2026년 10월 23일로 밝혔습니다. 대상에는 GPT-4 계열 스냅샷, GPT-3.5 Turbo, o1, o3-mini, o4-mini가 포함됩니다. 종료일이 지나면 이 모델 ID를 호출하는 요청은 실패합니다. 종료까지 나흘 남았으니 지금 코드와 설정에서 모델 ID를 확인하는 편이 안전합니다.

1. 종료되는 모델 ID를 먼저 찾으십시오

공식 표에 따르면 10월 23일에 종료되는 항목은 gpt-4-0613, gpt-4-turbo, gpt-4-1106-preview, gpt-3.5-turbo-0125, gpt-4o-2024-05-13, gpt-4.1-nano, o1, o1-pro, o3-mini, o4-mini, gpt-image-1입니다. 같은 이름이 별칭(alias)으로 쓰인 경우도 함께 확인하십시오. 예를 들어 gpt-4-turbo나 o4-mini를 고정해 쓰고 있다면 같은 날 종료 대상입니다.

2. 권장 대체 모델을 확인하십시오

OpenAI가 제시한 대체 모델은 대부분 gpt-5.6-sol, gpt-5.6-terra, gpt-5.6-luna입니다. GPT-4 계열과 o1, o3-mini는 gpt-5.6-sol로, o4-mini와 gpt-3.5-turbo는 gpt-5.6-terra로, gpt-4.1-nano는 gpt-5.6-luna로 옮기도록 안내돼 있습니다. gpt-image-1은 gpt-image-2.5-sunburst 또는 gpt-image-2.5-flare로 옮기면 됩니다. 대체 모델은 OpenAI의 추천일 뿐이므로 응답 형식, 도구 호출, 비용을 실제 요청으로 시험한 뒤 바꾸십시오.

3. 파인튜닝 모델은 따로 확인할 것

파인튜닝 모델도 같은 날 종료됩니다. ft-gpt-3.5-turbo, ft-gpt-4, ft-gpt-4.1-nano-2025-04-14, ft-babbage-002, ft-davinci-002, ft-o4-mini-2025-04-16가 목록에 있습니다. 파인튜닝 모델은 기본 모델을 바꿔도 자동으로 옮겨지지 않으므로, 새 기본 모델로 학습을 다시 하거나 평가 데이터로 결과를 비교해야 합니다.

4. 다음 종료일도 같이 잡아두십시오

10월 23일이 끝이 아닙니다. 같은 문서에는 2027년 1월 14일 종료되는 GPT-4o와 GPT-4.1 계열(gpt-4o-2024-08-06, gpt-4.1-2025-04-14 등)도 있습니다. 이 날짜는 10월 14일에 따로 공지됐습니다. 모델 목록은 한 번 점검해 두고 끝내지 말고, 공식 문서나 모델 목록 API의 shutdown_date 필드를 주기적으로 확인하십시오.
