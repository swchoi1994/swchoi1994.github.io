Checking Chrome extension permissions: How to reduce access to all sites first

Seongwoo Choi · 2026.10.30 · 2 min read

Learn how to review Chrome extension permissions, reduce access from all sites, and check important settings without assuming results from personal testing.

In this article

  • 1. Open the list of installed extensions
  • 2. View the site access scope in Details
  • 3. The order for reducing unnecessary permissions
  • 4. Points to note when checking

If you do not know which websites an extension installed in Chrome can read and modify, it is a good idea to reopen the list and check its permissions first. Extensions are convenient, but they often receive permission to read and change website data. This article is organized based on Google Chrome Help’s page on installing and managing extensions. I should first clarify that this is not the result of installing and testing extensions on my actual PC.

1. Open the list of installed extensions

From Chrome’s More (three dots) menu in the upper right, go to Extensions, then Manage extensions. You can also reach the same list by clicking the puzzle-shaped Extensions icon to the right of the address bar. You can stop an item you are not currently using by turning off its enabled switch. To remove it completely, right-click the icon next to the address bar and choose Remove from Chrome.

2. View the site access scope in Details

When you click Details on an extension card, you will see an option allowing the extension to read and change data on the websites it visits. You can choose the scope here. When you select On click, the extension works only in the tab and window opened by clicking its icon. On current site makes it work automatically on the site you are currently viewing. On all sites makes it work automatically on every site you visit. Of the three, On all sites grants the broadest permission, so it is efficient to review items with this setting first.

3. The order for reducing unnecessary permissions

First, turn off or delete extensions you do not use often. Second, find the remaining extensions set to On all sites and change them to On click. Third, if a feature is needed only on a specific site, add only that site’s address under the permissions section in Details. If a feature stops working, it is safer not to broaden the scope all at once, but to add the sites you need one at a time and check. If possible, do not add sensitive places such as banking or work-related sites to the list.

4. Points to note when checking

Menu names and locations may vary slightly depending on the Chrome version and language. On company or school PCs, an administrator may have blocked some extensions, so if an installation option is not visible, check the administrator’s policies before changing settings. To use an extension in Incognito mode, you must separately turn on Allow in Incognito in Details. When installing a new extension, keeping Enhanced protection turned on can provide warnings about untrusted extensions.
