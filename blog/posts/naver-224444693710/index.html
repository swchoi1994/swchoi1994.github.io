인텔 추론 GPU 480GB, 메모리 대역폭부터 계산해 볼 것

Seongwoo Choi · 2026.10.17 · 3분 읽기

인텔이 10월 12일 OCP Global Summit에서 데이터센터용 추론 GPU인 Intel GPU D-series(코드명 Crescent Island)의 기술 세부 정보를 공개했습니다. 회사 발표에 따르면 이 GPU는 최대 480GB LPDDR5X 메모리, 1.5TB/s 메모리 대역폭, FP8 기준 1.3페타플롭스 연산 성능을 갖추고 있습니다. 350W 전력 설계의 표준 PCIe 카드이고 공랭 방식입니다. 고객 샘플링은 이미 진행 중이라고 밝혔습니다.

1. 추론 GPU는 연산보다 메모리를 먼저 본다

언어 모델은 답변 토큰을 하나씩 만들 때마다 가중치를 메모리에서 읽습니다. 요청이 한 개뿐이면 연산 장치가 데이터를 기다리는 시간이 길어지고, 메모리 대역폭이 체감 속도를 정하는 경우가 많습니다.

간단한 계산을 해 보겠습니다. 파라미터 3,000억 개짜리 모델을 FP8로 한 장에 올리면 가중치만 약 300GB입니다. 1.5TB/s로 한 번 전부 읽는 데 약 0.2초가 걸립니다. 요청 한 개 기준 이론상 상한은 초당 약 5토큰입니다. KV 캐시와 소프트웨어 최적화에 따라 실제 값은 달라지므로, 이 숫자는 설명을 위한 가정입니다.

여러 요청을 묶어 처리하면 같은 가중치 읽기를 여러 요청이 나눠 쓰기 때문에 전체 처리량이 올라갑니다. 인텔이 Xeon 랙을 설명하며 목표 지연 시간에서 동시에 처리할 수 있는 에이전트 수를 성능 지표로 든 것도 같은 맥락입니다.

2. 발표 수치에서 확인할 세 가지

① 메모리 용량. 480GB면 300B급 모델을 카드 한 장에 올릴 수 있다는 뜻입니다. 인텔은 8개 GPU 시스템에서 1조 개 이상 파라미터 모델을 지원한다고도 밝혔습니다. 다만 이는 회사가 제시한 최대 구성 기준입니다.

② 대역폭 대비 연산 비율. 1.3페타플롭스를 1.5TB/s로 나누면 약 867 FLOP/byte입니다. 이 비율이 높을수록 연산 장치가 데이터를 기다리는 시간이 늘어나기 쉽습니다. 긴 문맥과 많은 동시 요청을 처리하는 작업이라면 연산 성능보다 대역폭 여유를 먼저 따져 볼 만합니다.

③ 설치 조건. 표준 PCIe 폼 팩터와 공랭 설계라서 전용 액체 냉각 없이 기존 서버에 넣을 수 있다는 것이 인텔의 설명입니다. 같은 날 공개된 Xeon 6+ 랙 구성은 선택 사양 기준으로 랙당 46,000코어 이상, 총 랙 전력 133.45kW입니다. 랙 단위로 보면 전원과 냉각 설계를 먼저 확인해야 합니다.

3. 아직 확인하지 못한 것

가격, 정식 출시 시점, 독립 벤치마크는 이번 보도자료에서 확인하지 못했습니다. 고객 샘플링은 정식 공급과 다릅니다. 경쟁 GPU와의 성능 비교도 공개되지 않았으므로, 지금은 발표 수치를 읽는 기준을 세우는 단계로 보는 것이 맞습니다.

4. 도입 검토 체크리스트

① 기존 서버에 PCIe 슬롯과 전력 여유가 있는지 확인합니다.

② 모델 가중치, KV 캐시, 동시 요청 수를 더해 필요한 메모리를 계산합니다.

③ 벤더 수치 대신 내 워크로드로 처리량과 지연 시간을 직접 측정합니다. 샘플링 기간이 있다면 이 단계에 쓰는 것이 낫습니다.
