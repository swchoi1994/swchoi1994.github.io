GitHub Copilot 11월 16일 모델 3종 제거, 고정해 둔 모델 설정부터 확인할 것

Seongwoo Choi · 2026.10.18 · 2분 읽기

GitHub가 10월 15일 changelog에서 Copilot의 모델 3종을 11월 16일 중단한다고 밝혔습니다. 대상은 Claude Opus 4.8, Claude Opus 5, GPT-5.6 Terra입니다. Copilot 채팅, 인라인 편집, Ask와 Agent 모드, 코드 완성 모두에 적용됩니다. 모델 자체가 사라지는 것은 아니고, Copilot에서 고르는 경로가 닫히는 것입니다. 그래도 모델명을 고정해 둔 팀은 11월 중순에 작업이 멈출 수 있습니다.

1. 바꿔야 할 모델을 먼저 확인하십시오

GitHub가 제시한 대체 모델은 다음과 같습니다. Claude Opus 4.8과 Claude Opus 5는 Claude Opus 5.5로, GPT-5.6 Terra는 GPT-6.1 Sol 또는 GPT-6 Luna로 바꾸라고 안내했습니다. 예외는 하나입니다. 개인 연간 요금제 구독자는 Claude Opus 4.8을 계속 쓸 수 있습니다. 기업과 비즈니스 요금제에는 이 예외가 적용되지 않습니다.

2. 기본값 자동 전환을 관리자가 확인할 것

기업과 비즈니스 고객은 기본 모델 활성화 설정에 따라 대체 모델이 자동으로 켜집니다. 관리자가 전역 기본값을 끈 상태라면 Copilot 설정의 모델 정책에서 대체 모델을 직접 켜야 합니다. 사용자는 Copilot Chat의 모델 선택기에서 새 모델을 보게 됩니다. GitHub는 중단 후 별도로 제거 작업을 할 필요는 없다고 적었습니다.

3. 점검 체크리스트 세 가지

첫째, 조직 정책과 개인 설정에서 모델명이 고정된 곳을 찾으십시오. 팀 문서, IDE 설정, 사내 가이드에 Opus 5나 Terra가 적혀 있다면 11월 16일 전에 바꿔야 합니다. 둘째, 대체 모델로 실제 작업을 한 번 돌려 보십시오. 같은 프롬프트라도 답변 길이와 코드 스타일이 달라질 수 있습니다. 셋째, 비용이 다른 모델로 바뀌는지 확인하십시오. GitHub 공지에는 가격 비교가 없어, 사용량이 많은 팀은 요금 페이지를 따로 봐야 합니다.

4. 모델 이름은 API 기준으로도 따로 확인할 것

같은 모델이 Copilot에서 빠져도 제작사 API에는 남아 있을 수 있습니다. 그래서 Copilot 설정 점검과 API 호출 코드 점검은 따로 해야 합니다. 이번 글과 같은 날 올린 Claude Sonnet 4.5 은퇴 글에서처럼, API 호출 중인 모델 ID 목록을 만들어 두면 두 경우를 한 번에 확인할 수 있습니다.
