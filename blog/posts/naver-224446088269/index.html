Meta Muse Wonder 공개, API 비용은 입력 4달러·출력 20달러부터 계산할 것

Seongwoo Choi · 2026.10.19 · 3분 읽기

Meta가 10월 12일 새 모델 시리즈 Muse Wonder를 공개했습니다. 기본 버전인 Muse Wonder(API 식별자 muse-wonder-1.0)는 Meta Model API와 Muse Code에서 쓸 수 있습니다. 상위 버전인 Muse Wonder Full은 Muse Code 구독자에게만 제공됩니다. 개발자라면 성능 발표보다 먼저 호출 비용과 접근 경로를 확인하는 편이 순서상 맞습니다.

1. 입력과 출력 단가를 따로 계산하십시오

Meta 개발자 모델 페이지 기준 muse-wonder-1.0은 100만 토큰당 입력 4달러, 캐시된 입력 0.20달러, 출력 20달러입니다. 컨텍스트 창은 1,048,576 토큰입니다. 출력 단가가 입력의 다섯 배이므로, 긴 문서를 읽고 짧게 답하는 작업과 긴 코드를 생성하는 작업은 비용 구조가 크게 다릅니다. 응답 길이 상한(max_tokens)을 설정하고, 호출 로그에서 출력 토큰 평균을 먼저 보십시오.

기존 코드를 고칠 범위도 확인하십시오. Meta는 OpenAI SDK 호환 클라이언트를 Meta Model API 주소로 향하게 하면 된다고 안내합니다. 다만 모델 이름, 도구 호출 형식, 스트리밍 응답은 실제 요청으로 한 번씩 확인해야 합니다. 호환 인터페이스가 있다는 것과 결과가 같다는 것은 다른 문제입니다.

2. Muse Wonder와 Full을 혼동하지 마십시오

Full 버전은 API로 호출하는 상품이 아닙니다. Meta 개발자 페이지는 Muse Code 구독 요금제 안에서 이 모델을 쓰도록 안내합니다. 요금제는 월 50달러(Power Usage)와 월 200달러(Maximum Usage) 등으로 나뉩니다. 자사 서비스에 붙일 계획이라면 API 버전의 단가와 지연 시간을 기준으로 설계해야 하고, Full 버전의 성능 수치를 그대로 비용 계산에 넣으면 안 됩니다.

3. 회사가 내세운 강점과 검증할 점

Meta는 두 가지 기능을 핵심으로 소개했습니다. Active Memory는 대화 사이에서 중요한 맥락을 기억했다가 작업에 맞게 꺼내 쓰는 기능입니다. Active Focus는 어려운 작업에서 다른 방법을 시도하고, 오류에서 회복하며, 중요한 행동 전에 확인을 요청하는 기능입니다. 법률, 금융, 건강 영역과 장기 소프트웨어 작업에서 최고 수준이라는 주장도 있습니다.

다만 FocusBench, SWE-Marathon 같은 평가 이름과 점수는 Meta가 설계하고 발표한 것입니다. 독립 기관의 평가가 나오기 전까지는 회사 주장으로 읽는 것이 맞습니다. 벤치마크 수치는 원문 이미지 표에만 있어 이 글에는 옮기지 않았습니다.

4. 도입 전에 확인할 세 가지

첫째, 실제 업무 문서 20~30개로 응답 품질을 기존 모델과 비교하십시오. 둘째, 1M 컨텍스트를 쓸 때 입력 토큰이 얼마나 쌓이는지 캐시 적중률과 함께 계산하십시오. 셋째, 메모리 기능을 켠다면 어떤 개인정보가 대화 사이에 남는지, 어떻게 지우는지를 먼저 정하십시오. Meta는 허락 없이 개인정보를 공유하지 않도록 학습했다고 밝혔지만, 추가 안전성 평가가 담긴 전체 보고서는 아직 준비 중이라고 밝혔습니다.
