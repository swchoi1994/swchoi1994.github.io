How to find and change the Windows screenshot save location: Distinguishing PrtScn and Snipping Tool

Seongwoo Choi · 2026.11.05 · 4 min read

When a Windows screenshot file is missing, identify the capture method first: Windows logo key + PrtScn saves directly to Pictures\Screenshots, while Snipping Tool may save automatically according to its settings.

  • 2. Open the Screenshots folder in File Explorer

When you take a screenshot in Windows but cannot find the file, it is easier to locate it if you first identify which capture method you used. Windows logo key + PrtScn saves the screen directly as an image file, while Snipping Tool opens an editing window after capture and automatically saves files according to its settings. This article organizes the steps for finding the save location and checking the settings based on official Microsoft Support documents. It is not the result of changing and testing the settings on an actual PC.

1. Identify the capture method first

The save location differs by capture method. When you use Windows logo key + PrtScn, the entire screen is saved in the Screenshots folder inside the Pictures folder. When you use Snipping Tool, you can capture a rectangle, window, full screen, or freeform selection, and the capture is saved in the same Screenshots folder when automatic saving is enabled.

In Snipping Tool, clicking “Save as” lets you create an additional copy in the location you want. This copy is created separately from the automatically saved file, so choose file names in advance to avoid confusion about which file to use.

2. Open the Screenshots folder in File Explorer

Open File Explorer from the taskbar and select the Pictures folder in the navigation pane on the left. Open the Screenshots folder inside it to see screenshots taken with Windows logo key + PrtScn. Microsoft Support documents provide the same path.

If the folder is empty, take a new screenshot and check again. Seeing whether a new file is created is the first thing to do before changing the settings. If there is still no file, proceed to the save-status check in section 4.

3. Check Snipping Tool’s automatic save settings

Open Snipping Tool, select Settings from the More (…) menu in the upper-right corner. According to Microsoft Support documents, captured items are automatically saved in the Screenshots folder, and the automatic save behavior or default Screenshots folder can be changed in these settings. Read the wording on the settings screen and choose the option you want.

Before turning automatic saving off or changing it, back up the files currently remaining in the Screenshots folder. After changing the settings, check once more where a new screenshot is created to reduce confusion.

4. Check whether the file was saved

If you took a screenshot but there is no file, it may exist only on the clipboard. In that case, you must save it from the program into which you pasted it. If you only edited the image in Snipping Tool without saving it, you must create the file manually with “Save as.”

On PCs that use cloud synchronization such as OneDrive, the Pictures folder may be in a synchronized location. Community questions also mention cases like this, but this article has not verified the cause through official documentation, so first check the actual location of the Pictures folder in File Explorer.

5. Points to note when moving the Screenshots folder

Community answers often introduce a method of moving the Screenshots folder by right-clicking it in File Explorer and using the Location tab in Properties. This method is mentioned for the Windows logo key + PrtScn capture folder; it was not tested directly for this article and was not verified in official Support documentation. Back up the original files before moving the folder, and check whether a new screenshot appears in the new folder afterward.

6. Summary: Order of checks

First, identify which key or app you used to capture the screen. Second, if you used Windows logo key + PrtScn, open Pictures > Screenshots. Third, if you used Snipping Tool, check the automatic save behavior under More > Settings. Fourth, if there is no file, check whether it remains only on the clipboard and whether you saved it. If personal information appears in the screenshot, check the steps for masking it before changing the save location.
