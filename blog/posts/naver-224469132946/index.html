When Excel numbers are stored as text: green-triangle conversion and the VALUE function

Seongwoo Choi · 2026.11.08 · 2 min read

If an Excel cell contains a number but the total is 0 or the value is aligned left, the number may have been stored as text. Based on Microsoft Support documentation, this article explains how to check the display and convert it back to a number.

1. Check the green triangle in the upper-left corner of the cell

Excel detects most numbers stored as text and displays a green triangle in the upper-left corner of the cell. Select the cell or range, click the error indicator button, or press Alt+Shift+F10, then choose 'Convert to Number.' The conversion is complete when the value becomes right-aligned and the triangle disappears.

2. When the error indicator button is unavailable

If the button is not visible, go to File > Options > Formulas and check whether 'Enable background error checking' is turned on. Microsoft’s documentation presents this setting as a way to check error indicators.

3. Create a helper column with the VALUE function

In an empty column next to the original, enter a formula such as =VALUE(E23) that references the text cell, then fill it down. To move the converted values back to the original column, copy the new column, select the first cell in the original column, and use Paste > Values (Ctrl+Shift+V). Because this process replaces formulas with values, it is safer to keep a copy of the original before overwriting it.

4. What to check after conversion

① Check whether the SUM result in the total cell is the expected value. ② Confirm that the alignment has changed to the right. ③ If leading zeros are meaningful in codes such as 00123, the leading zeros disappear when the value is converted to a number, so it is better to keep it as text. For how to enter leading zeros, see Excel leading-zero article ↗.

Checklist

① Find the green triangle ② Run Convert to Number ③ If the button is unavailable, create a VALUE helper column ④ Keep a copy before pasting values ⑤ Keep codes and phone numbers as text ⑥ Check the total and alignment again. If the total changes when a filter is applied, also see the SUBTOTAL article ↗; if a conditional count returns 0, see the COUNTIF article ↗.
