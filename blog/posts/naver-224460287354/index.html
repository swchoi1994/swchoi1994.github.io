How to Check and Delete ChatGPT Memory: Keep It Separate from Deleting Chats

Seongwoo Choi · 2026.10.31 · 3 min read

ChatGPT’s Memory feature uses preferences and context from conversations in future chats. This article explains how to check, edit, delete, and turn off memory, which is stored separately from chat history.

ChatGPT’s Memory feature uses preferences and context from conversations in future chats. However, it can be confusing to know whether information remains remembered after deleting a conversation. The key point is that chat history and saved memories are separate stores. Based on OpenAI Help Center guidance, this article explains how to check, edit, delete, and turn off memory.

1. First, see what is remembered

Go to Settings, then Personalization, and then Memory. Depending on the account and platform, items such as Memory summary and Saved memories may be shown. If the menu is not visible, the Help Center also suggests asking ChatGPT what it currently remembers about you.

2. Correct inaccurate information and exclude what you do not want mentioned again

Ask ChatGPT to correct inaccurate or outdated information, or edit the memory item directly. For information you do not want mentioned again, select the “Don’t mention this again” option when available. However, this only reduces its use for future personalization; it does not delete the original conversation or files.

3. Memory may remain separately even after deleting a conversation

The Help Center explains that saved memories are stored separately from the original conversation and are not automatically deleted when you delete the conversation. Therefore, you need to check both. First, delete the saved memory item. Second, look for the same information in conversations, archived conversations, the file repository (Library or Space), and connected apps. It may take time for deletion to take effect, and OpenAI states that it may retain logs of deleted memories for up to 30 days for safety and debugging purposes.

4. What to distinguish when turning off memory

Turning off memory stops the creation and use of new memories. However, past conversations are not deleted. If you turn off Reference chat history, information obtained from past conversations is scheduled for deletion from OpenAI systems within 30 days. Conversely, turning off Reference saved memories also turns off reference to chat history. Check the setting names first to confirm which feature is being disabled.

You can also use Temporary Chat for sensitive questions. According to the release notes, Temporary Chat does not use or update memory and does not appear in history. However, information obtained from that conversation will not be remembered later, so choose it based on whether it suits your purpose.

5. Review checklist

1) Open the memory section in Settings and read the saved information.

2) Correct inaccurate information and delete items you want removed.

3) Find the conversation where the information originated and decide whether to delete it.

4) Check connected apps and the file repository for the same information.

5) If you will no longer use the feature, turn off memory and check the scope of the reference settings.

6) Decide in advance whether to use Temporary Chat for sensitive questions.
