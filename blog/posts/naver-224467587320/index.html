How to defer Windows Update restarts outside your active hours: distinguishing active hours from restart scheduling

Seongwoo Choi · 2026.11.06 · 3 min read

After installing a Windows update, you may need to restart your PC to finish. If a restart occurs while you are working, unsaved content could be lost. Based on Microsoft Support pages, this article explains how to use “Active hours” to defer restarts outside your usage hours and distinguishes this from “Schedule the restart,” which lets you choose a specific time.

1. Active hours and restart scheduling are different features

The Microsoft Support page explains that when you need to restart your PC to finish an update, setting active hours can reduce the chance of a restart occurring while you are using it. Active hours set a rule that means “do not restart during this time.” By contrast, restart scheduling lets you choose the date and time yourself. Which one to use depends on whether your work hours are consistent or you want to avoid restarts only on specific days.

2. How to set active hours

In Windows 11, open Start > Settings > Windows Update > Advanced options. Select Active hours, then choose automatic or manual from the “Adjust active hours” list. If you choose automatic, Windows determines the time range based on the device’s usage history. If you choose manual, enter the start and end times yourself and save them. Menu names may vary slightly depending on the Windows version.

3. Choose a specific time with restart scheduling

The Microsoft Support FAQ explains that Windows tries to restart when you are not using the device and, if that is not possible, asks you to schedule a restart at a more convenient time. To choose one yourself, select “Schedule the restart” under Start > Settings > Windows Update, then choose a convenient time. If you have documents open before scheduling, it is safest to save them first.

4. Example: a PC used from 9 a.m. to 6 p.m.

This is a hypothetical example. Suppose you use your PC from 9 a.m. to 6 p.m. on weekdays and set active hours to 09:00–18:00. You can then expect the restart to be deferred until outside those hours. However, this is only a schedule example; the actual restart time depends on the type of update and the device’s condition. If a device must avoid restarting during work, it is better to save important work and also set a restart schedule.

5. What to check after setup

First, keep a laptop connected to its charger. The Microsoft FAQ advises that sufficient power is required to finish installing updates outside active hours. Second, check Settings > Windows Update > Update history to see which updates were installed and when. Third, if you want to defer installation temporarily, you can use “Pause updates,” but according to the FAQ, you must install the latest updates before you can use the pause count again, so it is not a permanent blocking method.

6. How to choose based on the situation

If your work hours are fairly consistent, use manual active hours. If your usage hours change frequently, enable automatic adjustment. If you need to defer a restart immediately, use pause; if you want to set a restart time, use restart scheduling.
