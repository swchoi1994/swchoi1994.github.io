How to recover deleted files in Windows: distinguishing the Recycle Bin, cloud storage, and Windows File Recovery

Seongwoo Choi · 2026.11.05 · 3 min read

When you accidentally delete a file, first check where it may still exist—your PC’s Recycle Bin, a cloud Recycle Bin such as OneDrive, or a backup—before installing recovery software, following Microsoft’s official guidance.

In this article

  • 1. First, look in the Windows Recycle Bin
  • 2. Check the cloud Recycle Bin and backups
  • 3. Reduce use of the drive before recovery
  • 4. Check the Windows File Recovery command format
  • 5. Check recovered files separately from the originals

When you accidentally delete a file, the first thing to do is not install recovery software, but check in order where the file may still exist. The method differs depending on whether it is in your PC’s Recycle Bin, a cloud Recycle Bin such as OneDrive, or a backup. This article organizes the checking order based on Microsoft’s official support documents. It is not the result of testing recovery on an actual PC.

1. First, look in the Windows Recycle Bin

If the file is in the Windows Recycle Bin, recovery is simple. Open the Recycle Bin, select the file, right-click it, and choose Restore to return the file to its original folder. Microsoft’s support documentation also gives these steps for restoring a file from the Recycle Bin. If there are multiple files with similar names, check the file name and original location together and select them one at a time.

2. Check the cloud Recycle Bin and backups

Files deleted from OneDrive or SharePoint may not appear in the PC’s Recycle Bin. Microsoft’s support documentation explains that files deleted in the cloud may not be visible in the computer’s Recycle Bin and may be restorable on the web. Therefore, first check the OneDrive web Recycle Bin in a browser, and also check whether the same file exists in Windows Backup. If it can be restored from a backup, this method is safer than using recovery software.

3. Reduce use of the drive before recovery

Microsoft’s Windows File Recovery documentation explains that reducing or avoiding computer use can increase the chance of recovering a file. The space occupied by a deleted file is marked as available free space, but a new file can overwrite that space when it is saved. Therefore, it is best to postpone installing new programs on the drive being recovered or downloading large files whenever possible.

4. Check the Windows File Recovery command format

If you cannot find the file in the Recycle Bin or a backup, you can use the Windows File Recovery (winfr) command-line app installed from the Microsoft Store. The basic format in the official documentation is winfr source-drive recovery-drive [mode] [options]. The source and recovery drives must be different. For example, when recovering part of the Documents folder on drive C to drive E, the official example uses /regular mode together with the /n filter. The username portion of the user-folder path must be replaced with the actual account name.

The official table advises using Regular mode for an NTFS drive from which files were recently deleted, and Extensive mode for files deleted long ago, after formatting, or from a corrupted drive. If you are unsure, it says to try Regular mode first. When there are many file types, it is advisable to narrow the search with the /n option by specifying a file name or extension.

5. Check recovered files separately from the originals

After recovery is complete, the files are saved in a folder with the format Recovery_date-and-time, which Microsoft creates on the recovery drive. Open the files and first confirm that their contents are correct before moving them to their original locations. If a file with the same name already exists, carefully choose whether to overwrite it, and it is safer to keep separate copies of important files. Because recovery commands do not guarantee that the results will always be complete, it is best to follow the order of checking backups first whenever possible.

In summary, checking in the order of the Recycle Bin, cloud Recycle Bin and backups, and Windows File Recovery can reduce unnecessary work. If you want to clean up storage after deleting files, it is best to distinguish temporary files from personal files first.
