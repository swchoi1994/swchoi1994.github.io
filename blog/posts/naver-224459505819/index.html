Claude Code installation and first login: what to check

Seongwoo Choi · 2026.10.30 · 3 min read

Claude Code lets you open a project folder in a terminal and read and edit code with AI, but checking the login account and API key before first use can help prevent unexpected charges.

  • 2. Choose the installation command for your operating system

Claude Code is a tool that lets you open a project folder in a terminal and read and edit code with AI. The installation command is a single line, but if you do not check which account is used at first launch, a billing method different from what you expect may be applied. This article organizes the steps to check during installation and the first login, based on Anthropic’s official documentation. It is not the result of installing it directly on an actual device.

1. Conditions to check before installation

The requirements listed in the official installation documentation are as follows. The operating system must be macOS 13.0 or later, Windows 10 1809 or later or Windows Server 2019 or later, Ubuntu 20.04 or later, Debian 10 or later, or Alpine Linux 3.19 or later. At least 4 GB of memory is required, and an internet connection is needed for installation and login. Also check the list of supported countries.

2. Choose the installation command for your operating system

The method recommended in the official documentation is native installation. On macOS, Linux, and WSL, enter curl -fsSL https://claude.ai/install.sh | bash in the terminal. In Windows PowerShell, use irm https://claude.ai/install.ps1 | iex, and in CMD, use the command that downloads install.cmd. Entering the PowerShell command in CMD causes an error, so first check the prompt format (PS C:\ or C:\).

You can also install it with Homebrew (brew install --cask claude-code) or WinGet (winget install Anthropic.ClaudeCode). These two methods do not update automatically, so you must periodically run brew upgrade or winget upgrade. On Windows, you must also install Git for Windows to use Bash tools. WSL does not require Git for Windows.

3. Check the version: claude --version

After installation is complete, open a new terminal window and enter claude --version. If a version number and (Claude Code) are displayed, the installation was successful. If you see a message saying that the claude command cannot be found, the installation path may not yet be in PATH, so check the PATH section of the official installation troubleshooting documentation.

4. First launch and checking the login account

When you run claude in a project folder, a login prompt appears. The official quickstart documentation recommends Claude Pro, Max, Team, and Enterprise subscription accounts, and also introduces a Claude Console account, which uses the API with prepaid credits, as an option. Before logging in, check which account you are entering with and whether that account uses a subscription or API credits. Accounts from cloud providers are also covered separately in the documentation.

5. Billing may differ if an API key environment variable exists

According to the quickstart documentation, if the ANTHROPIC_API_KEY environment variable is set and you approve the screen asking whether Claude Code should use that key, the login process is skipped. In this case, usage may be processed as API usage rather than through a subscription login. Before the first launch, check whether ANTHROPIC_API_KEY appears in the list of environment variables, and do not approve it if you did not intend to use it. There is no need to copy the key value itself into a screen or article.

6. Post-installation checklist

① Check the version number with claude --version. ② Note the installation method (native, Homebrew, or WinGet) and the update method. ③ Check whether the ANTHROPIC_API_KEY environment variable exists. ④ Check the type of login account. ⑤ Run claude in an empty practice folder and view the command list with /help. Open an actual project only after that.
