DeepSeek V4.1-Flash-1017 공개, 개발자가 모델명과 검색 API 가격부터 확인할 것

Seongwoo Choi · 2026.10.18 · 3분 읽기

중국 DeepSeek가 2026년 10월 17일 DeepSeek-V4.1-Flash-1017을 공개했습니다. 회사는 이전 버전보다 성능이 높아지고, 작업 완료 시간과 출력 길이가 줄었다고 밝혔습니다. 개발자에게 중요한 부분은 점수 자체보다 모델명 변경, 검색·페치 API 가격, 가중치 공개 방식입니다. 세 가지를 나눠서 확인해 보겠습니다.

1. 벤치마크는 측정 조건부터 볼 것

허깅페이스 모델 카드에 따르면 DeepSWE v1.1은 이전 V4.1-Flash의 74.2점에서 77.0점으로, Terminal-Bench 4.0은 31.2점에서 42.3점으로 올랐습니다. 같은 표에서 Claude Opus 5는 DeepSWE v1.1 74.0점, Terminal-Bench 4.0 51.8점입니다. 반대로 도구 없이 푸는 HLE 점수는 42.6점으로, Opus 5의 56.3점보다 낮습니다.

회사는 Terminal-Bench 4.0을 Claude Code 하네스로, DeepSWE v1.1을 Mini-SWE-V2 하네스로 측정했다고 밝혔습니다. 하네스가 바뀌면 같은 모델도 점수가 달라질 수 있으므로, 자신의 작업 환경에서 같은 조건으로 한 번 돌려 보는 것이 안전합니다.

2. 검색·페치 API는 호출 단위로 계산할 것

검색(Search)과 페치(Fetch) API는 각각 1,000회 호출당 0.75달러입니다. 회사 발표에 따르면 DeepSeek Harness, Claude Code, Codex에서 서버 측 도구로 호출하는 검색·페치는 현재 무료이며, 유료 청구는 2026년 10월 31일 16:00 UTC부터 시작합니다.

예를 들어 에이전트가 검색 1,000회와 페치 1,000회를 쓰면 기본 가격으로 1.50달러입니다. 실제 비용은 에이전트가 검색을 몇 번 반복하는지에 달려 있으므로, 테스트 로그에서 호출 수부터 세어 보는 것이 좋습니다.

3. 기존 API 코드에서 바꿀 부분

공식 문서 기준 새 모델명은 deepseek-flash입니다. 기존 deepseek-v4-flash와 deepseek-v4-flash-vision-exp 이름은 아직 받지만, 해당 모델은 퇴역했고 요청은 V4.1-Flash로 처리되며 Flash 가격으로 청구됩니다. 기존 코드는 당장 동작하지만, 장기적으로는 모델명을 바꿔 두는 편이 좋습니다.

가중치는 MIT 라이선스로 허깅페이스와 ModelScope에서 받을 수 있습니다. 컨텍스트 창은 100만 토큰이고, 권장 샘플링은 temperature 1.0, top_p 1.0입니다. 다만 이 배포에는 Jinja 채팅 템플릿이 들어 있지 않습니다. 대신 encoding 폴더의 Python 참조 구현을 쓰고, 운영용으로는 deepseek-recipe 라이브러리도 함께 공개되어 있습니다.

4. 확인할 점

첫째, 벤치마크 수치는 DeepSeek가 자체적으로 낸 것이며, 독립적인 재현 결과는 아직 찾지 못했습니다. 둘째, 가격과 무료 기간은 현재 공지 기준이므로 청구가 시작되기 전에 공식 문서를 다시 확인하십시오. 셋째, 이번 글의 도표는 모델 카드 수치를 옮긴 설명용 그림이며, 직접 실험한 결과가 아닙니다.
