Workday 헤드리스 AI 에이전트, 로그인 없이 일하는 구조에서 확인할 것

Seongwoo Choi · 2026.10.17 · 4분 읽기

기업용 AI 에이전트가 사람이 시스템에 로그인하지 않은 상태에서도 인사와 재무 데이터를 다룰 수 있게 됐습니다. Workday는 Oct 13th 2026 Workday Rising 2026에서 자사 Trusted Agent Platform을 헤드리스(headless) 구조로 바꿨다고 발표했습니다. 화면 없이 도구 형태로 기능을 제공하고, 어떤 에이전트든 Workday의 권한과 승인 규칙 안에서 실행하는 방식입니다.

1. 헤드리스가 바꾸는 것

에이전트가 기업 데이터를 쓰려면 보통 복사본을 만들거나 별도 연결을 거칩니다. Workday 보도자료는 이 방식의 위험을 두 가지로 설명합니다. 거버넌스 없는 데이터 복사본을 에이전트가 읽으면 보면 안 되는 급여 정보까지 볼 수 있고, 시스템 계정으로 연결하면 승인 없이 행동할 수 있다는 것입니다. Workday의 대응은 Agent-Ready Tools라는 MCP 도구입니다. 요청자가 누구인지, 무엇을 보고 실행할 수 있는지, 어떤 승인이 필요한지, 행동을 어떻게 기록할지를 매 요청에 함께 실어 보냅니다.

2. 에이전트 하네스가 맡는 일

Workday 기반 에이전트는 모두 Agent Harness 위에서 돌아갑니다. 하네스는 작업자의 역할, 보고 라인, 볼 수 있는 범위와 적용 정책을 에이전트에 전달합니다. 각 행동을 관리하고, 작업을 비용과 성능에 맞는 모델로 배정한다고 설명합니다. 자율 에이전트 발표문에 따르면 에이전트가 한 모든 행동은 기록되어 무엇을 했고, 어떤 정보를 썼고, 누가 승인했는지 확인할 수 있습니다.

3. 자율 에이전트를 채용 예시로 보기

발표에서 가장 구체적인 예는 채용 에이전트(Talent Acquisition Agent)입니다. 공고가 올라오면 후보자를 찾고, 리크루터에게 자격과 부족한 부분을 정리해 줍니다. 면접 일정 조율과 피드백 초안도 맡습니다. 다만 후보자에게 보내는 연락은 리크루터가 승인해야 나갑니다. 회사는 어떤 작업을 자동으로 돌릴지, 어디서 사람이 최종 결정할지 고를 수 있습니다. 조기 도입 고객부터 쓸 수 있다고 합니다.

4. 지금 쓸 수 있는 것과 예정된 것

- 일반 공개(GA): Agent Harness, Agent-Ready Tools, Custom Agents, Developer Agent, Workday Data Cloud

- 조기 공개(early access) 예정: Agent Context Service는 2026년 말, Grounded Reasoning은 2027년 초입니다.

- 발표만 된 기능: Payroll Agent, Accounting Agent, Deployment Agent의 자율 기능은 출시일이 없습니다. Google ADK 지원은 design partner 모집 단계입니다.

같은 발표에서 NVIDIA Nemotron 오픈 모델 지원은 정식 공개(GA)되었다고 밝혔습니다. 앞서 올린 Nemotron 3.5 Super VL 글과 함께 보면 에이전트에 붙일 모델 선택지를 비교할 수 있습니다. [관련 글: 엔비디아 Nemotron 3.5 Super VL·Bolt 공개](https://blog.naver.com/swchoi1994/224444351394)

5. 도입 전 확인할 네 가지

첫째, 에이전트가 쓸 권한 범위가 어디까지인지 확인하십시오. 둘째, 실행 기록을 내보내 감사팀이 검토할 수 있는지 보십시오. 셋째, 실행 빈도가 비용에 주는 영향을 계산하십시오. 보도자료는 빈도를 정할 수 있다고만 말하고 가격은 밝히지 않았습니다. 넷째, 연결하려는 모델이 정책을 제대로 따르는지 직접 시험하십시오. Workday도 자체 연구에서 LLM이 올바른 정책 문서가 있어도 HR 정책을 잘못 적용할 수 있다고 인정했습니다.

주의: 이 글의 수치와 효과 표현은 모두 Workday 발표 기준입니다. 채용 기간이 주 단위에서 일 단위로 줄어든다는 내용도 회사 주장이며 독립적으로 검증하지 않았습니다. 한국 고객 지원 여부와 가격은 확인되지 않았습니다.
