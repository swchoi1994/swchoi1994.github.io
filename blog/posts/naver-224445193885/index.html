Gemini 4 Argon Google Cloud 출시, 도입가 종료일 11월 30일부터 단가를 계산할 것

Seongwoo Choi · 2026.10.18 · 2분 읽기

구글이 최상위 모델인 Gemini 4 Argon을 Google Cloud에서 쓸 수 있다고 밝혔습니다. 구글 클라우드 블로그는 Argon을 '새로운 프런티어 모델'로 소개하며, 긴 작업을 여러 단계에 걸쳐 끝까지 이어가는 능력을 강조했습니다. 성능 주장은 뒤에서 따져 보기로 하고, 개발자에게 먼저 중요한 것은 가격 구조입니다. 도입가가 언제 끝나는지에 따라 같은 호출 비용이 두 배로 달라지기 때문입니다.

1. 도입가는 2026년 11월 30일까지입니다

구글 클라우드 블로그에 따르면 Argon의 도입가는 입력 100만 토큰당 2달러, 출력 100만 토큰당 10달러입니다. 캐시된 입력 토큰은 95% 할인되어 계산하면 100만 토큰당 0.10달러입니다. 도입가는 2026년 11월 30일까지 적용되며, 이후에는 입력 100만 토큰당 4달러, 출력 100만 토큰당 20달러가 적용됩니다.

2. 고객 사례는 회사가 고른 결과입니다

클라우드 블로그는 GitLab, Harvey, ServiceNow, Figma의 코멘트를 실었습니다. Harvey는 법률 에이전트 평가에서 Gemini 3.1 Pro 대비 개선이 컸다고 말했습니다. ServiceNow는 조기 접근 기간에 Gemini 3.8 Flash보다 작업 성공률이 약 20% 높았다고 밝혔습니다. 구글 내부 사례로는 Chrome 팀이 Chromium 코드베이스에서 수백 개 파일에 걸친 구조 개편을 마쳤다는 내용과, ADK 팀이 장기 세션의 메모리 내 세션 준비 시간을 40% 줄였다는 내용이 있습니다.

모두 회사와 고객이 전한 결과입니다. 이 글을 쓰는 시점에 독립 기관이 같은 조건에서 재현한 수치는 확인하지 못했습니다. 벤치마크 이름과 측정 조건을 함께 보고, 자신의 작업으로 다시 측정해야 합니다.

3. 가격 계산은 입력과 출력을 따로 봐야 합니다

예를 들어 입력 100만 토큰과 출력 20만 토큰을 쓰는 작업이 있다고 가정하겠습니다. 도입가에서는 입력 2달러와 출력 2달러로 합계 4달러입니다. 정상가로 바뀌면 입력 4달러와 출력 4달러로 합계 8달러가 됩니다. 실제 청구는 캐시 적중률과 사용 조건에 따라 달라질 수 있으므로, 이 계산은 설명용 예시입니다.

4. 확인 목록

첫째, 현재 쓰는 Gemini 모델과 Argon의 입력·출력 토큰 비율을 사용 로그에서 확인하십시오. 출력이 많은 작업이라면 출력 단가 인상이 더 크게 작용합니다. 둘째, 같은 프롬프트 세트로 현재 모델과 Argon을 비교 테스트하십시오. 셋째, 모델 ID, 최대 토큰, 구독 요금제별 접근 범위는 구글 공식 모델 카드와 개발자 문서에서 확인하십시오.

같은 Gemini 계열의 도입가 조건은 [Gemini 3.8 Flash 가격 글](https://blog.naver.com/swchoi1994/224444550624)에서 정리했습니다. 두 모델을 비교할 때는 기준 날짜를 같게 맞추면 판단이 쉬워집니다.
