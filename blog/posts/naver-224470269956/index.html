When Windows text is blurry or small: the order for separating text size, scaling, and resolution

When on-screen text looks too small or blurry, many people change the resolution first. But the right setting depends on the cause. This article explains what to check when only text is small, everything is small, or the display is blurry or cut off. The settings paths are based on Microsoft Support documentation.

1. When only text is small: adjust the text size

If only text within Windows—such as title bars, menus, and icon names—looks small, adjust the text size first. Microsoft Support advises pressing the Windows logo key and U, or going to Settings > Accessibility, then dragging the text size slider to the right and selecting Apply. This method enlarges only the text while leaving the overall display scaling unchanged.

2. When everything looks small: change the scaling

If you want images and apps to appear larger or smaller along with the text, go to Settings > Display > Scale & layout > Scale and choose a value. According to the document, the change applies immediately to most items, but some apps may require you to sign out and sign back in for the change to be fully applied. After changing the scale, open the apps you use frequently and check that text is not cut off or overlapping.

3. When the display is blurry or cut off: check whether the resolution is recommended

If the display still looks blurry or its edges appear cut off after changing the scale, check whether the resolution is set to the recommended value in the same display settings screen. This step is this article’s troubleshooting order, not a procedure from Microsoft’s documentation. If you selected a resolution other than the recommended value, restore the recommended value and check the result. Make a note of the current resolution before changing it so it is easier to restore.

4. Checklist

1) Determine whether only the text is small, the entire display is small, or the display is blurry or cut off. 2) If only the text is small, raise the text size slider and select Apply. 3) If the entire display is small, choose a scale and, if necessary, sign out and sign back in. 4) If the display is blurry or cut off, compare the resolution with the recommended value.

5. Related articles to check

If you have just connected an external monitor, scaling may appear different on each monitor. For cable or detection issues, first see What to check when an external monitor is not detected ↗. If a window is completely out of sight because it is outside the screen, it is covered separately in How to recover a Windows window that disappeared off-screen, and the keyboard shortcuts ↗.

The examples in this article are not results confirmed by changing settings on an actual PC. Menu locations may vary slightly depending on the Windows version and manufacturer settings.
