How to create a Windows recovery drive: Preparing a blank USB and backing up personal files

Seongwoo Choi · 2026.11.08 · 2 min read

Create a Recovery Drive in advance for serious Windows problems, using a blank USB for system files and updates while backing up personal files separately.

Creating a Recovery Drive in advance can help if Windows will not start or the system is severely damaged. A recovery USB contains Windows system files and installed updates, but not personal files such as photos or documents. This article outlines the order for preparing the USB, creating the drive, and backing up personal files based on Microsoft Support documentation.

1. Prepare a blank USB

Creating a recovery drive erases all content on the selected USB. Use a blank USB with no important files, and check first whether there are any files on it that you want to keep before plugging it in. Since the official documentation does not specify a fixed USB capacity, follow the guidance shown on the tool's screen.

2. Create it with the system file backup option

Search for Recovery Drive in the Start menu and open it, or enter recoverydrive.exe in the Run window. When the tool opens, select the Back up system files to the recovery drive option and click Next. Select the USB from the list and click Create to begin copying. This may take some time, so wait until the completion message appears.

3. Back up personal files separately from the recovery drive

Microsoft explains that personal files are not included on a recovery drive and recommends using another method, such as File History or Windows Backup. Photos, documents, and Desktop files should be stored in a location separate from the recovery USB. How to find already deleted files is covered separately in How to recover deleted files in Windows ↗.

4. Check which option to choose when starting with the recovery USB

The method for starting a PC from USB differs by manufacturer, so check the manufacturer's documentation first. When the Windows Recovery Environment (Windows RE) opens, choose Recover from a drive, then select either Just remove my files or Fully clean the drive. Both choices can erase data, so confirm that you have a backup of your personal files before proceeding.

5. Check other methods first for system file problems

If the computer starts but only some features are malfunctioning, you can check Windows system file check: when to use sfc /scannow and DISM ↗ before using the recovery USB. Remembering that a recovery drive is a tool used during a full reinstallation makes it easier to determine the proper order.

6. Preparation checklist

1) Prepared a blank USB and confirmed that its existing data would be erased. 2) Created the drive with the system file backup option selected. 3) Stored photos and documents separately using File History or Windows Backup. 4) Consider creating the recovery USB again about once a year after Windows updates. 5) Checked the method for entering the boot menu in the manufacturer's documentation.
