What are Claude Skills? Distinguishing official and community resources in a post about 400 agents

Seongwoo Choi · 2026.10.22 · 3 min read

Claude Skills do not install hundreds of new AI models. They bundle instructions, reference materials, and scripts for recurring tasks in one folder for an agent to read when needed. When viewing a post claiming that “Claude runs more than 400 specialized agents,” distinguish the number of resources, whether they are officially provided, and their actual execution capabilities.

1. Resources bundled in shared posts have mixed sources

The LinkedIn post shared by the reader introduces several GitHub repositories at once. Their nature differs depending on the repository owner. anthropics/claude-quickstarts and anthropics/knowledge-work-plugins are repositories under the anthropics organization. msitarzewski/agency-agents, wshobson/agents, and addyosmani/agent-skills are projects under different owners. This does not mean community resources are bad, but calling the entire list “official Skills newly released by Anthropic” would be incorrect.

The figure of 400 is also a claim made by that post. Within the scope of our review, we could not verify that figure from the repository list alone.

2. Skills, agents, and plugins are different units

According to Anthropic’s explanation, a Skill is a folder containing a SKILL.md file. At the beginning of the file is a YAML header containing a name and description. At startup, only these two fields are added to the system prompt, and the body is read when a relevant task arises. Reference files are opened only when needed, using a progressive disclosure approach. The original text is available in the official Anthropic article ↗.

An agent is an entity that performs tasks using tools, while a plugin is a unit that bundles multiple functions for easier installation. What is actually included and how far it is supported depends on the product being used and the installation method.

3. Example repositories may not be Skills ready for immediate installation

claude-quickstarts ↗ is a collection of examples for building apps with the Claude API. Examples include a customer support agent and financial data analysis. The repository README states that a Claude API key is required. In other words, even if the repository can be downloaded for free, API call costs may arise separately. Likes and GitHub star counts do not demonstrate safety or suitability for a task.

4. Hypothetical example: a customer inquiry response Skill

The following is a hypothetical example for explanation. For customer inquiry response work, you could record the company’s tone, the order information that must be checked, and the conditions for handing a case to a staff member in one folder. You would not need to explain the same procedure at length every time. However, such a Skill does not automatically grant permission to read customer data or send email. This is not the result of installing an actual plugin and measuring its performance.

5. Pre-installation checklist

1) Owner: First check from the repository address whether it belongs to an official organization, an individual, or a community.

2) License: Check the repository’s license file for the conditions governing use, modification, and redistribution.

3) Connected permissions: Note what the resource accesses among files, email, calendars, and external APIs.

4) Change scope: Check which configuration files or folders will change after installation.

5) Operating costs: Calculate whether an API key, subscription, or cloud usage fee is required.

After recording these five items, it is safer to review one needed function first.

6. What this article did not do

During the preparation of this article, we did not install the introduced repositories or connect any accounts. We also did not evaluate performance or rankings by repository. The date of verification is October 22, 2026.
