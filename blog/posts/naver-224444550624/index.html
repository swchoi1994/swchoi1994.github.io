Gemini 3.8 Flash 도입가 종료 예정, 2027년 1월부터 API 비용 확인할 것

Seongwoo Choi · 2026.10.17 · 3분 읽기

Google은 Sep 2nd 2026에 Gemini 3.8 Flash를 공개하면서 입력 100만 토큰당 0.75달러, 출력 100만 토큰당 3.75달러의 도입가(introductory price)를 적용했습니다. 이 가격은 Dec 31st 2026까지만 적용되고, Jan 1st 2027부터는 입력 1.50달러, 출력 7.50달러로 두 배가 됩니다. API 비용 예산을 올해 단가로만 세우면 내년 초에 숫자가 어긋납니다.

1. 바뀌는 단가

Google은 3.8 Flash가 3.7 Flash와 같은 도입가를 적용한다고 밝혔습니다. 발표문 각주에 따르면 Jan 1st 2027 이후 표준 요금은 입력 100만 토큰당 1.50달러, 출력 100만 토큰당 7.50달러입니다. Google 가격 페이지도 출력 요금에 추론 토큰(thinking tokens)이 포함된다고 적고 있습니다. 모델이 내부적으로 더 많이 추론할수록 출력 쪽 비용이 올라갑니다.

2. 월 비용으로 옮겨 보기

가정 하나를 두겠습니다. 한 달에 요청 1만 건을 보내고, 요청 하나당 입력 2,000토큰, 출력 500토큰을 쓴다고 봅니다. 그러면 한 달 입력은 2,000만 토큰, 출력은 500만 토큰입니다.

현재 도입가로 계산하면 입력 15달러, 출력 18.75달러, 합계 33.75달러입니다. Jan 1st 2027 단가를 적용하면 입력 30달러, 출력 37.5달러, 합계 67.5달러입니다. 같은 트래픽이라도 월 비용이 정확히 두 배가 됩니다. 이 숫자는 설명을 위한 가정이며 실제 청구서가 아닙니다. 캐시, 배치, 요금 한도 같은 조건에 따라 실제 결과는 달라질 수 있습니다.

3. 개발자가 할 수 있는 점검 세 가지

① 예산표를 2027년 단가로 한 번 더 계산합니다. 고객 요금제나 연간 예산을 정할 때 도입가를 기준으로 잡으면 마진이 한 번에 깨질 수 있습니다.

② 작업별로 모델을 나눕니다. 분류나 추출처럼 단순한 요청은 더 저렴한 모델로 보내고, 긴 추론이 필요한 요청만 3.8 Flash로 보내는 방식입니다. 이때 출력 토큰 안에 추론 토큰이 들어간다는 점을 계산에 넣어야 합니다.

③ 토큰 단가보다 '성공한 작업 1건당 비용'을 측정합니다. 단가가 같아도 답이 짧고 재시도가 적은 모델이 실제로는 더 싸게 끝날 수 있습니다. 전체 트래픽을 한 번에 바꾸기보다 일부 요청만 먼저 보내 보는 카나리(canary) 방식이 안전합니다.

4. 아직 확인되지 않은 것

Google은 3.8 Flash의 소프트웨어 엔지니어링과 에이전트 작업 성능이 개선됐다고 발표했습니다. 이는 회사 발표이며, 이 글에서 직접 재현하지 않았습니다. 2027년 이후 가격이 그대로 유지될지도 공개 문서만으로는 알 수 없습니다. 예산을 확정하기 전에 가격 페이지를 다시 확인하는 편이 좋습니다.

같은 주제의 이전 글은 [Gemini 4 Argon 정식 제공, 도입가 기간에 개발자가 확인할 것](https://blog.naver.com/swchoi1994/224443282682)에서 확인할 수 있습니다.
