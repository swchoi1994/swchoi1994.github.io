Claude Sonnet 4.5 API 11월 30일 은퇴, 호출 중인 모델 ID부터 확인할 것

Seongwoo Choi · 2026.10.18 · 2분 읽기

Anthropic이 Claude API에서 Sonnet 4.5 모델의 은퇴(retirement) 일정을 공지했습니다. 공식 문서 기준으로 claude-sonnet-4-5-20250929는 2026년 9월 30일 지원 중단(deprecated) 상태가 됐고, 은퇴일은 11월 30일입니다. 은퇴 뒤에는 이 모델을 부르는 요청이 실패합니다. 이 모델명이 코드나 설정 파일에 들어 있는 서비스라면 날짜 전에 바꿔야 합니다.

1. 바꿀 모델 ID와 대체 모델

공식 표는 claude-sonnet-4-5-20250929의 권장 대체 모델로 claude-sonnet-5-5를 지정합니다. 날짜가 붙은 전체 ID를 쓰는 곳과 짧은 이름을 쓰는 곳을 나눠서 검색하십시오. 같은 서비스 안에서도 워커마다 다른 모델명을 쓰는 경우가 많습니다.

2. 남은 기간과 플랫폼별 차이

Anthropic은 공개 모델을 은퇴시키기 최소 60일 전에 고지한다고 문서에 적었습니다. 9월 30일 공지부터 11월 30일까지는 61일입니다. 다만 이 날짜는 Claude API, Claude Platform on AWS, Microsoft Foundry 기준입니다. Amazon Bedrock과 Google Cloud는 자체 모델 표와 일정을 따로 씁니다. 두 플랫폼을 쓴다면 해당 표를 별도로 확인해야 합니다.

3. 실제 사용처 찾기

코드 검색만으로는 크론 작업, 오래된 배치 스크립트, 다른 팀의 설정을 놓치기 쉽습니다. Claude Console의 Usage 페이지에서 Export를 누르면 API 키와 모델별 사용량이 담긴 CSV를 받을 수 있습니다. 이 파일에서 claude-sonnet-4-5-20250929 사용 기록이 남은 키가 교체 대상입니다. 키마다 담당자를 정해 두면 누락을 줄일 수 있습니다.

4. 교체 전 확인할 세 가지

첫째, 같은 입력 묶음으로 기존 모델과 대체 모델의 출력을 비교하십시오. 응답 형식, JSON 구조, 도구 호출 방식이 바뀌었는지 보는 것이 우선입니다.

둘째, 응답 길이와 지연 시간, 비용을 함께 재십시오. 모델이 바뀌면 같은 작업의 토큰 사용량도 달라질 수 있습니다.

셋째, 실패 시 되돌릴 설정을 미리 준비하십시오. 모델명을 환경 변수로 빼 두면 배포 없이 되돌릴 수 있습니다. 이는 실무 권장안이며 Anthropic의 공식 절차가 아닙니다.

5. 같이 볼 일정과 이전 글

같은 문서에 Claude Opus 4.5(claude-opus-4-5-20251101)의 은퇴일이 '11월 24일 이후'로 잠정 표기돼 있습니다. 확정 날짜가 아니므로 공지가 나오면 다시 확인해야 합니다. 모델을 바꿀 때는 에이전트의 권한 범위도 함께 점검하십시오. 이전 글: [클로드가 실제 사이트에서 예상 밖 행동을 한 이유와 AI 에이전트 권한 관리](https://blog.naver.com/swchoi1994/224443237114)
