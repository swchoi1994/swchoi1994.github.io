Gemini API 미리보기 모델 10월 22일·23일 종료 표기, 호출 ID와 대체 모델부터 확인할 것

Seongwoo Choi · 2026.10.19 · 2분 읽기

Google Gemini API 사용 중단 표에 10월 22일과 23일 종료 예정일이 적혀 있습니다. 대상은 미리보기(preview) 모델입니다. 정식(GA) 모델과 달리 미리보기 모델은 일정이 짧게 바뀔 수 있으므로, 이번 주 안에 호출 코드를 한 번 점검하는 편이 안전합니다.

1. 10월 22일: Omni 미리보기와 Veo 3.1 미리보기

표 기준으로 gemini-omni-flash-preview는 6월 30일에 나온 미리보기이고, 종료 예정일은 10월 22일입니다. 대체 모델은 gemini-omni-1.1-flash입니다. 같은 날짜에 Veo 3.1 미리보기 계열(veo-3.1-generate-preview, veo-3.1-fast-generate-preview, veo-3.1-lite-generate-preview)도 표에 올라 있으며, 표는 이들의 대체 모델도 gemini-omni-1.1-flash로 적고 있습니다.

날짜가 한 번 바뀐 점도 확인하십시오. 8월 27일 릴리스 노트는 gemini-omni-flash-preview의 사용 중단을 9월 30일로 예고했습니다. 현재 표는 10월 22일을 가장 이른 종료일로 적고 있습니다. 옛 공지만 보고 일정을 짐작하면 안 됩니다.

2. 10월 23일: Deep Research 미리보기

deep-research-pro-preview-12-2025는 10월 23일 종료 예정입니다. 릴리스 노트는 대체 방법으로 interactions.create 요청의 agent 값을 deep-research-preview-04-2026으로 바꾸라고 안내합니다. 더 깊은 조사가 필요하면 deep-research-max-preview-04-2026도 선택지입니다. 에이전트 호출 설정 파일에서 이 문자열을 먼저 찾으십시오.

3. 11월 17일 항목과 점검 순서

같은 표에서 gemini-3.1-flash-live-preview와 gemini-3.1-flash-tts-preview 등 음성 미리보기 모델은 11월 17일로 적혀 있습니다. 실시간 음성 기능을 쓰고 있다면 10월 중에 대체 모델 gemini-3.8-live 계열로 옮길 계획을 세우십시오.

점검 순서는 세 단계입니다. 첫째, 코드, 환경 변수, 저장된 작업 목록에서 위 모델 ID를 검색하십시오. 둘째, 대체 모델에 실제 요청을 몇 개 보내 응답 형식과 토큰 비용을 비교하십시오. 셋째, 종료일이 지나면 호출이 실패하므로 날짜 전에 전환을 끝내십시오. 표는 종료일을 '가장 이른 가능한 날짜'로 적고 있어, 정확한 날짜는 Google이 따로 알린다고 명시합니다. 그래서 날짜를 믿고 미루기보다 먼저 옮기는 편이 낫습니다.
