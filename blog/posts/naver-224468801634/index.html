How to freeze panes in Excel so header rows stay visible while scrolling long tables

Seongwoo Choi · 2026.11.07 · 3 min read

In Excel, select the cell directly below and to the right of the rows and columns you want to freeze, then choose View > Freeze Panes so they remain visible while you scroll.

When a table is long in Excel, the top header row disappears as you scroll down, making it easy to lose track of which column is which. The Freeze Panes feature keeps the top rows and left columns visible while you scroll through the rest. In short, select the cell directly below and to the right of the rows and columns you want to freeze, then click Freeze Panes on the View tab. The steps below are based on Microsoft's official support documentation.

1. Select the reference cell

Freeze Panes freezes the rows above and the columns to the left of the selected cell. Therefore, select the cell in the row immediately below the row you want to freeze and the column immediately to the right of the column you want to freeze. For example, select cell A2 to freeze only row 1, or select cell B2 to freeze both row 1 and column A. Check this reference cell carefully at the first step, because selecting the wrong cell may also freeze unwanted rows or columns.

2. Apply Freeze Panes from the View tab

On the ribbon, select View > Freeze Panes > Freeze Panes in order. If the View tab is not visible, you may be using Excel Starter, and Microsoft states that some features are not supported in this version.

3. Example of freezing columns

If you want to keep seeing a name or number column while moving across the table to the right, select the column immediately to the right of the last column you want to freeze, then click Freeze Panes in the same menu. This is the method shown in Microsoft's example, “Freeze the first two columns.” To freeze rows and columns together, select the cell immediately below and to the right of the area you want to freeze.

4. Check by scrolling and unfreeze

After setting it up, move the table down and to the right to check that the header row and reference column remain visible. To remove the freeze, select View > Freeze Panes > Unfreeze Panes. If you want to change the settings, it is safer to unfreeze them first and then select the reference cell again.

5. Do not confuse it with print titles

Freeze Panes applies only when scrolling on screen. To repeat a header row on each printed page, you need to use a separate setting such as Print Titles. Print scaling issues are covered separately in How to fit an Excel table to one page wide when it is cut off during printing ↗. If you are unsure about the input format for number columns, you may also want to see Four ways to enter leading zeros in Excel without them disappearing ↗.

Checklist

① Confirm the locations of the header rows and reference columns to freeze ② Select the cell immediately below and to the right ③ Select View > Freeze Panes > Freeze Panes ④ Scroll down and to the right to check ⑤ If it is not correct, select Unfreeze Panes and set it up again
