How to schedule Night light in Windows: sunset to sunrise or set a custom time

Seongwoo Choi · 2026.11.07 · 3 min read

To turn on Night light automatically when the screen feels too bright in the evening, enable scheduling in Settings > System > Display > Night light, then choose sunset to sunrise or set custom times.

  • 4. Turn it on and off immediately from Quick settings

If the screen feels too bright in the evening and you want to turn on Night light automatically, enable scheduling in the Display menu of the Settings app. In short, go to System > Display > Night light, turn on Schedule night light, choose sunset to sunrise or set custom times, and check whether the screen changes to warmer colors after the scheduled time. The steps below are based on official Microsoft help, and menu names may vary slightly depending on the Windows version and language.

1. Open the Night light settings

Go to Start > Settings > System > Display. You can also reach the same screen by entering Night light in the Settings search box. Because this menu handles brightness and color together, you may need to change the brightness using the monitor's own buttons if the brightness slider is not visible on an external monitor.

2. Turn on the scheduling switch

On the Night light screen, turn on the Schedule night light switch. If this switch is off, the display will not change automatically at the scheduled time, leaving only the option to turn it on and off manually from Quick settings.

3. Choose sunset to sunrise or set custom times

If you choose sunset to sunrise, Windows adjusts the schedule automatically. If you have set evening work hours, choosing a custom schedule and entering the times to turn it on and off yourself is easier to predict. You can also adjust how much blue light is reduced with the Strength slider.

4. Turn it on and off immediately from Quick settings

If you want to use it immediately instead of waiting for the schedule, click the network or speaker icon on the right side of the taskbar and turn Night light on or off from the Quick settings list. Think of this as a manual switch that operates separately from the scheduled setting.

5. What to check when automatic switching does not work

First, if the Night light switch appears gray and cannot be used, update the display driver. Microsoft says that a driver update may be required in this case. Second, official help states that Night light cannot be used on devices using DisplayLink or the basic display driver, so first check whether the feature is unavailable in that environment. Third, Microsoft Community includes a user report that Night light did not change even after the scheduled time passed following an update, but turned on after a restart. This is not an official solution, but a reference case, so check by saving the settings again, restarting once, and then checking the status.

6. Do not confuse it with color calibration

Calibrate display color, which you look for when the screen colors appear unusual, is a different feature from Night light. If your goal is to reduce blue light, check the Night light settings; if your goal is to match colors for photos or design work, check color calibration separately. Changing both features at once can make it difficult to identify the cause, so it is best to change one at a time.
