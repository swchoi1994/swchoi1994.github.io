How to check a Windows Wi-Fi password: Select Show in the settings of a connected PC

Seongwoo Choi · 2026.11.07 · 2 min read

If you forget a Wi-Fi password, the quickest method is to view it again on a Windows PC already connected to that Wi-Fi network. In short, select Show next to the Wi-Fi network password in the Network & internet settings menu. The steps below are based on Microsoft’s official support documentation.

1. Check whether the PC has the password saved

This method can be used only on a Windows PC that has connected to that Wi-Fi network at least once. A device that has never connected will not have a value to display, so first check the router’s administration screen or the label on the back of the device. If the PC is managed by a company or school account, some menus may be restricted.

2. Open Network & internet in Settings

Open the Settings app and select Network & internet. Menu names may vary slightly depending on the Windows version and language, so look for the name displayed on your screen.

3. Show the password for the currently connected network

In Network & internet, select Properties, then select Show next to the Wi-Fi network password. The password will appear on the screen, so first check whether anyone nearby can see it, write down the necessary value, and then close the screen.

4. Find another saved Wi-Fi password

For a network you are not currently connected to, open Manage known networks from the Wi-Fi menu. Select the network from the list, then select Show in the same Wi-Fi network password section. If it is not listed, it was not saved on that PC, so you will need to find another method.

Checklist

① Find a Windows PC that has connected to that Wi-Fi network ② Open Settings > Network & internet ③ Show the Wi-Fi network password in Properties ④ For another network, select it in Manage known networks ⑤ Check your surroundings and close the screen

Things to keep in mind when copying or writing it down

If you copy the password, it may remain in your clipboard history. For how to manage the history, see How to turn Windows clipboard history on and clear it: Steps to prevent copied passwords from remaining ↗. If you are connected but cannot access the internet, Wi-Fi internet troubleshooting steps ↗, which divides the possible causes among the PC, router, and telecommunications provider, may be more appropriate.
