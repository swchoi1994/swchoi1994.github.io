How to check whether your laptop battery life has declined: the order for reading a powercfg battery report

Seongwoo Choi · 2026.11.06 · 3 min read

If your laptop shuts down sooner or lasts less on one charge, use Windows’ powercfg battery report to distinguish high app usage from reduced battery capacity and assess battery aging.

If your laptop shuts down sooner than before or lasts less time on a single charge, there are two main possible causes: an app that is currently using a lot of power, or the battery itself holding less charge than it did initially. This article explains how to check the latter by creating a battery report with the built-in Windows command powercfg. App usage is covered separately in The order for checking app-by-app usage when your laptop battery drains quickly ↗.

1. App problems and battery aging are different questions

App-by-app usage tells you which apps are using power right now. Battery aging, on the other hand, looks at how much the battery’s actual capacity when fully charged has decreased from its original capacity. Cleaning up apps may immediately increase usage time, but if the battery itself has significantly degraded, no amount of settings changes will restore its previous performance. Therefore, a reasonable order is to check the battery’s condition in the report first, then review apps and power-saving settings.

2. Create a report in Command Prompt

Open Command Prompt or Terminal from the Start menu and enter the following format. If you do not specify a save location, the report is created as an HTML file in the current location. To choose a location, use the /output option. Example: powercfg /batteryreport /output "C:\Users\username\Desktop\battery-report.html". Replace username with your account folder name. When the command finishes, open the generated HTML file in a browser.

If you want to view only the most recent few days, you can specify the period in days with the /duration option. The example in Microsoft’s documentation is powercfg /batteryreport /duration 4. A shorter period makes it easier to see recent changes, but to assess battery aging, also check whether enough of your usual usage history remains recorded.

3. The two capacities to compare in the report

The report includes both the capacity the battery was originally designed to hold (design capacity) and its current capacity when fully charged (full charge capacity). The item names or table layout may vary depending on the Windows version, so read the names exactly as they appear on the screen. This article is a hypothetical example showing how to calculate the result, not a report based on an actual report that was created.

For a hypothetical example, if the design capacity is 50,000 mWh and the full charge capacity is 40,000 mWh, the current capacity is 80% of the design capacity (40,000 ÷ 50,000 = 0.8). The important point is not to decide whether the battery needs replacement based on a single number. You should consider the period of use, charging habits, and usage history shown in the same report together.

4. The order for reading the results

① First, check the difference between the design capacity and the full charge capacity. ② In the same report, look for days when the battery dropped sharply or for records of long usage. ③ If the difference is large and usage time has actually decreased, consider contacting the manufacturer’s service center or an authorized service provider to ask for a battery inspection. ④ If the difference is small, first check the app-by-app usage described above and How to choose between sleep and hibernation on a laptop ↗.

5. What to check before sharing the report

Because the report contains the device’s usage history, review its contents before sending it to a repair technician or someone else, and provide only the necessary files. The manufacturer may also provide a separate diagnostic tool, so it is a good idea to check the manufacturer’s support page as well. If you want to see the processes currently running first, refer to The order for finding the processes causing a slow PC with Task Manager ↗.
