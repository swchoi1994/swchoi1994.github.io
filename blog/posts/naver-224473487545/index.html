What to check when a PDF will not upload to Gemini Notebook: file size, word count, and copy protection first

Seongwoo Choi · 2026.11.11 · 3 min read

When a PDF import fails in Gemini Notebook, first check the file size, word count, copy protection, and whether scanned text is available, then narrow the question scope and verify citations against the original.

  • 2. Check whether the PDF is copy-protected

If importing a PDF into Gemini Notebook fails, it is better to check the file itself first rather than changing how you ask questions. This article organizes the checks into four steps, based on the import-failure conditions listed in Google's official Help FAQ. The results were not obtained by uploading files to an actual account, and interface wording may change.

1. Check the file size and word count first

The official Help documentation limits a single source to 500,000 words or fewer and local file uploads to 200 MB or less. If either condition is exceeded, the file cannot be imported. Since it states that there is no page-count limit, you do not need to assume that a file failed simply because it has many pages.

If the file is large, you can divide one report into multiple files. When splitting it, avoid breaking chapters and sections, and add sequence numbers to the filenames so that sources are easier to find later.

2. Check whether the PDF is copy-protected

The Help documentation states that importing may fail if the original PDF is copy-protected. Check the file properties or PDF security settings to see whether copying is restricted. If it is restricted, consult the person who has permission to save the original document; do not use tools to bypass the protection.

3. If it is a scan, check whether the text is actually present

If the text exists only as images, as in a PDF made from photographs, there may be less body text available for answers. The Help documentation explains that when source content is short, the entire document is shown as the basis instead of individual sentences. If the text cannot be copied, refer to the process for checking whether OCR is needed first. OCR results should be checked against the original line by line for numbers and dates.

See How to check whether OCR is needed when PDF text cannot be copied ↗ first to make it easier to distinguish scanned documents from text PDFs.

4. Narrow the question scope after importing

According to the Help documentation, sources are always used for questions, and answers are based on either all sources or selected sources. Notes are used only when directly selected, while conversation history is used to create answers. Therefore, even if importing succeeds, a broad question may mix in content from an unrelated document. When asking about one document, it is safer to select only that source.

The question sequence for reducing omissions when summarizing a long document is separately organized in Question sequence and verification checklist for reducing omissions when summarizing a long PDF with AI ↗.

5. Points to keep in mind

The Help documentation says that there is currently no way to recover a deleted note. It is best to export important notes to a document before deleting them. You should also open the citation numbers and compare them with the original to check whether the answer matches the cited sentences. The absence of a citation does not mean something is untrue, and the presence of a citation does not guarantee that it is correct.

Limitations of this article

The limits are based on the official Help documentation checked when this article was published. Product names and plan-specific limits may change, so it is safest to check the official Help documentation again before actually uploading a file. This article does not measure the results of running a specific PDF.
