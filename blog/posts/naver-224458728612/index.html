Excel #DIV/0! Error: How to Fix It When the Divisor Is 0 or Blank

Seongwoo Choi · 2026.10.30 · 2 min read

When an Excel division formula shows a #DIV/0! error, the divisor is usually 0 or blank. This article explains how to check it and distinguish between hiding errors and fixing their cause, using a fictional example table.

When an Excel division formula shows a #DIV/0! error, it usually means that the value being divided by (the denominator) is 0 or blank. This article explains the order for checking the denominator and the difference between hiding errors and fixing them, based on Microsoft Support documentation. The example below is a fictional table for explanatory purposes and is not the result of testing an actual worksheet.

1. Find the denominator in the cell with the error

For example, if cell C2 contains =A2/B2 and B2 is blank, the denominator is B2. First, find the cell address to the right of the division symbol (/) in the formula bar. Even when a function is used, check in the same way whether the argument being divided by is receiving 0 or a blank.

2. Check whether the denominator cell is 0 or blank

Microsoft Support explains that #DIV/0! occurs when a formula contains 0 or refers to a blank cell. Click the denominator cell and check whether its actual value is 0 or whether it contains nothing. If it appears to contain a value but still does not calculate, also check whether the cell contains a number or text.

3. Determine whether the blank is expected or an error

If the table is waiting for input, it is appropriate to leave the blank as it is and hide only the error. Conversely, if a value should be present but the cell is blank, first check whether the value was lost during data import or copying. Without making this distinction, you may see an incorrect total even after hiding the error.

4. Three ways to fix the formula

① Change the reference: Fix the formula so that the denominator refers to a different cell that is not 0. ② Use an IF condition: Calculate only when the denominator is present, as in =IF(B2,A2/B2,""). If B2 is 0 or blank, the condition is false and a blank is returned. ③ Use IFERROR: Replace the error with 0, as in =IFERROR(A2/B2,0).

Microsoft Support warns that the IFERROR and IF(ISERROR()) approaches hide all errors, not just #DIV/0!. Therefore, it is best to confirm that the formula is working properly before applying them.

5. Checks to perform before applying the change

① Copy the original formula separately. ② Use a filter to review only rows where the denominator is 0 or blank. ③ After applying the new formula, compare the number of rows and the total with your expectations. ④ Check that replacing errors with 0 does not distort averages or ratios. Whether to enter 0 or leave a blank in an average depends on the purpose of the calculation.
