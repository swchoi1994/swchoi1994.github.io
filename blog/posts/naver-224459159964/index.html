How to send a Gmail attachment as a Drive link when it exceeds the size limit

Seongwoo Choi · 2026.10.30 · 3 min read

Gmail’s attachment limit for personal accounts is 25 MB. When the total exceeds the limit, Gmail removes the file and replaces it with a Google Drive link; this guide explains how to check the limit and choose the right method.

  • 2. Calculate the total size of multiple files
  • 3. Choose between a direct attachment and a Drive link
  • 4. Set sharing permissions for the recipients
  • 5. Check storage space and the recipient’s limit

Sometimes Gmail shows a size-limit notice after you try to send a file, or the email is sent without the attachment. The attachment limit for personal Gmail accounts is 25 MB. Google explains that when the total attachment size exceeds the limit, Gmail removes the file from the email and replaces it with a Google Drive link. This article outlines how to check the limit and decide whether to use a direct attachment or a Drive link. This is a checklist based on Google’s support documents, not a result tested with actual emails.

1. First check whether it is a personal or company account

Personal Gmail accounts have an attachment limit of 25 MB. For Google Workspace accounts provided by a company or school, the administrator sets separate sending and receiving limits. The result may differ for the same file depending on the account, so if you are using a company account, check the limit set by the administrator first.

2. Calculate the total size of multiple files

Google describes the limit based on the total attachment size, not the size of each individual file. Several files may exceed the limit even if each one is small. Check whether the combined size of all the files you plan to send is 25 MB or less. For large files such as videos, using a Drive link is safer.

3. Choose between a direct attachment and a Drive link

If the total is within the limit, upload the file using the Attach button at the bottom of the compose window. If it exceeds the limit, choose the file under Insert files using Drive at the bottom of the compose window, then select Drive link. Files created with Google Docs, Sheets, or Slides cannot be attached directly and can only be sent as Drive links.

4. Set sharing permissions for the recipients

When you choose a Drive link, Gmail checks whether the recipients can access the file. If they do not have access, a notice appears asking you to change the sharing settings. If you choose 'Anyone with the link,' you can select Viewer, Commenter, or Editor. To make the file visible only to the email recipients, click 'More.' In this case, people without a Google account cannot open the file. If the email is forwarded or participants are added, the same permissions as those given to the original recipient apply, so see Google Drive sharing link permissions ↗ for information on distinguishing permissions.

5. Check storage space and the recipient’s limit

Attachments use the Google storage space shared by Gmail, Drive, and Photos. When storage is full, you cannot send or receive files. If an email will not send, check storage usage first; methods for organizing large attachments are described in Google storage cleanup ↗. If the recipient uses a company account, that organization’s receiving limit may be lower.

6. Checklist before sending

① Check whether the account is personal or a company account. ② Calculate the total size of the attachments. ③ If the total is 25 MB or less, attach the files directly; if it exceeds 25 MB, use a Drive link. ④ Choose Drive link permissions according to the recipients. ⑤ Check the Sent folder to confirm that the attachment or Drive link was actually included.

The official sources consulted are Google Support: Send attachments with your Gmail message ↗ and Google Support: Send Google Drive attachments in Gmail ↗. Menu names may vary depending on the account language and screen size, so check them together with the English names.
