How to rename multiple Windows files at once: PowerRename preview and undo

Seongwoo Choi · 2026.11.08 · 2 min read

This article explains how to safely batch-rename files with Microsoft PowerToys PowerRename, including previewing changes, checking extensions, and undoing the most recent change.

  • 3. Check the target files and extensions

  • Checklist

When you receive many photos or documents, their similar names, such as IMG_0001 and scan_03, can make them difficult to find. Renaming them one by one takes time, and undoing an incorrect change can be troublesome. This article outlines how to safely batch-rename files using PowerRename in PowerToys, as described by Microsoft.

1. First check whether the PowerRename menu is visible

PowerRename is a batch-renaming tool included in PowerToys for Windows. In File Explorer, select files, right-click, and check whether 'Rename with PowerRename' is visible. If the menu is not there, check whether PowerRename is enabled in PowerToys settings. Microsoft documentation also explains that this menu appears only when it is enabled in PowerToys.

2. Enter the search and replacement strings and view the preview

Enter the text to find in 'Search for' and the replacement text in 'Replace with'; the preview window then shows the original and changed names together. Read these results before confirming. There are three options to distinguish: ① Match all occurrences: when enabled, it replaces all instances of the same text; when disabled, it replaces only the first match. ② Case sensitive: when enabled, it distinguishes uppercase and lowercase letters. ③ Use regular expressions: when enabled, it interprets the input as a regular expression. At first, it is safer to leave regular expressions off and test with ordinary text.

3. Check the target files and extensions

Before replacing, check in File Explorer whether extensions are visible. If you batch-change names while extensions are hidden, you may misread the file types. The Windows file extensions article ↗ separately explains how to check double extensions. Select target files grouped by the same type. If you mix photos and documents, the search string may match unintended files.

4. Check after applying and undo the change

Microsoft documentation explains that completed name changes in PowerRename can be undone. The document's demo description also shows undoing the last change with Ctrl+Z (undo rename) in File Explorer. However, because Ctrl+Z is based on the most recent change, it may be difficult to undo only the desired step after making several consecutive changes. For important files, it is safer to copy the original folder before working.

Checklist

① Turn on PowerRename in PowerToys ② Select only files of the same type ③ Show extensions ④ Enter text in Search for and check the preview ⑤ Check Match all occurrences and Case sensitive ⑥ After applying, check the file count and names ⑦ If there is a problem, undo with Ctrl+Z. If you need to decide on an order before combining multiple files, also see the PDF merging article ↗.
