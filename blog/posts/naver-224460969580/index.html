What to Check When Files Do Not Appear in Windows Search: Start with Indexing Status and Excluded Folders

Seongwoo Choi · 2026.11.01 · 3 min read

When a file does not appear in Windows Search, the index may still be running or the folder may be excluded. This guide follows Microsoft’s official documentation, starting with the least costly checks.

In this article

  • 1. Check the indexing status message
  • 2. Check whether the folder you are looking for is indexed
  • 3. Check the file type and search process
  • 4. Make Rebuild the last step
  • 5. If the problem still persists

When a file that is clearly on your computer does not appear in the Windows search box, it is easy to think the file has disappeared. However, in many cases, the search index has not finished yet, or the folder containing the file is not included in indexing. Based on guidance from Microsoft’s official documentation, this article organizes checks in order, starting with those that require the least effort. These steps were not tested on an actual PC, and the wording shown on screen may vary depending on the Windows version.

1. Check the indexing status message

Open the Searching Windows page in Settings. In Windows 11, it is under Privacy & security. If the status says “Indexing complete,” indexing has finished. If it says “Indexing in progress,” new files are still being added, so wait several hours and keep the computer connected to power. If indexing has stopped because of the battery, connect the charger first. On a company PC, an administrator policy may be configured to stop indexing while the computer is running on battery power, so check with your IT team.

2. Check whether the folder you are looking for is indexed

In Advanced indexing options on the same page, click Modify to see the list of indexed locations. If the location you are looking for, such as the Documents folder, is not checked, files in that folder will not appear in search results. Check the same screen for any excluded folders. If you do not know where the file is located, first note its path in File Explorer and compare it with the list to save time.

3. Check the file type and search process

The File Types tab on the Advanced screen shows how each extension is indexed. For example, if you want searches to include the contents of text files, check whether the relevant extension is configured to index file contents. According to the documentation, you can change how each extension is handled or add new formats from this tab. If the search box is unresponsive, end SearchHost.exe in Task Manager (SearchUI.exe on Windows 10); it will restart during the next search. If that does not work, restart the PC.

Running msdt.exe -ep WindowsHelp id SearchDiagnostic in an elevated Command Prompt opens the Search and Indexing troubleshooter. Select the problems found by the troubleshooter and run it, and Windows will attempt to take corrective action.

4. Make Rebuild the last step

If the checks above do not solve the problem, run Rebuild from the Advanced screen. Microsoft explains that rebuilding the index database can take up to 24 hours. Search results may be incomplete during that time. According to the status table in the documentation, indexing slows when the PC is busy, so it is better to start it while the computer is connected to power and is not being used heavily. This recommendation is the author’s own summary.

5. If the problem still persists

Microsoft’s documentation also provides a PowerShell method for restoring Windows Search to its default state. Administrator privileges and a check of the execution policy are required, and script execution may be blocked on company PCs. The documentation explains that this reset does not delete files, but the ranking of search results may temporarily change. Before copying and running a command from the internet, compare it character by character with the command in the official documentation.
